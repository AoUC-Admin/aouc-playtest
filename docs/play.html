Install the whole game

  1. Use the download link shared with you by the developer to obtain the complete ZIP.
  2. Check its SHA-256 against the supplied checksum.
  3. Extract the entire ZIP into a new writable folder. Run play-game.cmd and keep the included model, runtime and notices together.
  4. If the normal launcher cannot render on your PC, try play-compatibility.cmd and report the exact error.

Testing is free. Keep the unlisted download link out of public reports. The package includes local inference: no Ollama installation, subscription or player API key is required.

Saves and upgrades

Start a new campaign if you are coming from the old Friends/Branch 05 build. Those saves are intentionally unsupported and must stay with their old game. Current Branch 07 campaigns remain supported; back them up before updating.

Keep your old installation. Do not extract over it. Saves live beside the executable in its saves folder. Copy supported saves only while both games are closed; the local profile is separate.

Alpha limits

  • This is an alpha. Long-session pacing, writing, balance and hardware coverage still need player feedback.
  • The Charterlands are the playable realm. Four other continental realms are lore and future production scope.
  • Local AI can reject responses and use authored fallback. Generated adventures use bounded game-owned opportunities, not unlimited autonomous plots.
  • No measured campaign-length guarantee or universal hardware-performance claim is made.

Mature fantasy themes include violence, blood, alcohol, fictional drugs and dark subject matter. No formal age rating has been assigned.
