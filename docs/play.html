Branch 08 changes and testing limits

Free playtest · Download link shared with testers

The game is available through an unlisted link from the developer. There is no purchase or paid beta requirement. The download link is not published on this website.

Install the whole game

  1. Use the download link shared with you by the developer to obtain the complete ZIP.
  2. Check its SHA-256 against the supplied checksum.
  3. Extract the entire ZIP into a new writable folder. Run play-game.cmd and keep the included model, runtime and notices together.
  4. If startup or local dialogue fails on your PC, try play-compatibility.cmd and report the exact error.

Testing is free. Keep the unlisted download link out of public reports. The package includes local inference: no Ollama installation, subscription or player API key is required.

Saves and upgrades

Back up supported current-family campaigns before updating. Historical Branch 05 saves remain unsupported and must stay with their original builds.

Keep your old installation. Do not extract over it. Saves live beside the executable in its saves folder. Copy supported saves only while both games are closed; the local profile is separate.

Alpha limits

  • This is a development alpha. Long-session pacing, writing, balance and broader hardware coverage still need player feedback.
  • The Charterlands are playable; four other realms remain future scope.
  • Local dialogue may need extra startup time and can fall back to authored responses.
  • Artwork is static. Human playthrough and commercial content review remain open.

Mature fantasy themes include violence, blood, alcohol, fictional drugs and dark subject matter. No formal age rating has been assigned.
